# Tennis career matches

STAT 159, Fall 2026, HW3 — James Wang

A minimal Python package for retrieving singles matches from Tennis Abstract
and plotting player age against player age minus opponent age, colored by result.

The package is being rebuilt on `james_hw3_rebuild`. This first commit contains
only the installation configuration; retrieval, plotting and tests follow.

The structure follows the October 26 Python packaging lecture and Lab 09:
a package folder, `__init__.py`, modules, `pyproject.toml` and offline tests.
