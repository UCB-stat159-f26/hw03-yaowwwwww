Q2. How should the opponent age field be handled?
A2. Convert an eight-digit birth date to age using the source match date.
    Keep decimal ages as given. Warn about missing ages and omit them in plots.

Q3. How can tests avoid downloading data every time?
A3. Use the small male/female examples from HW3 and mock HTTP responses.
    Block network access during pytest so an accidental request fails.

Q5. Can you show me how to write and run a small test?
A5. Pick fixed input, calculate the expected answer, and compare the result.
    This example checks an opponent's age without downloading anything.
    Save as test_age.py:
        import pandas as pd
        import pytest
        from tennis_career.data import _get_opponent_ages

        def test_opponent_age():
            dates = pd.Series(pd.to_datetime(["1995-10-30"]))
            birthdays = pd.Series(["19770119"])
            ages = _get_opponent_ages(birthdays, dates)
            assert ages.iloc[0] == pytest.approx(6858 / 365.25)

    Run in the terminal, in the folder containing test_age.py:
        python -m pip install pytest
        python -m pytest -q test_age.py
